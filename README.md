# Aggresome_MCC: Viral-antigen overexpression effects on proteostasis-related pathways

This repository contains the code and analysis used to investigate
aggresome- and proteostasis-related pathways following viral antigen
overexpression. The results are a part of "Merkel cell polyomavirus oncoprotein promotes BAG3-mediated aggresome formation" by Wang et al.

## Code authors

Libuše Janská

Department of Oncology-Pathology, Karolinska Institutet, Sweden

## Data source

The bulk RNA-seq data was originally generated by Yang et al, and is described in further detial at [(doi: 10.1172/JCI177724)](https://doi.org/10.1172/jci177724). Raw gene counts were downloaded from the GEO database, series [GSE130639](http://ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE130639). The samples of interest for the present analysis are human embryonic fibroblasts expressing **Merkel cell polyomavirus** (MCPyV) **truncated large tumor antigen (TLT)**, **early region (ER)**, and **GFP control** inducible vectors at 24 or 48 hours after induction.

This project uses `renv` for package management.

To reproduce the analysis:

```r
install.packages("renv")
renv::restore()
```
